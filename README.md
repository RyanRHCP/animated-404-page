# 🎨 Página 404 Animada

Uma página de erro 404 personalizada, desenvolvida com HTML, CSS e JavaScript, com o objetivo de apresentar uma interface visual criativa e proporcionar uma experiência mais agradável ao usuário durante a navegação.

## 📌 Sobre o projeto

A página 404 é exibida quando um usuário tenta acessar um endereço que não corresponde a uma página disponível.

Neste projeto, a proposta foi transformar uma mensagem de erro tradicional em uma experiência visual mais interessante, utilizando um personagem animado, elementos gráficos e uma interface intuitiva.

O projeto foi desenvolvido utilizando tecnologias fundamentais do desenvolvimento web, sem depender de frameworks JavaScript.

## ✨ Funcionalidades

- Página de erro 404 personalizada.
- Personagem com animação visual.
- Mensagem informativa para o usuário.
- Botão para retornar à página inicial.
- Interface visual com elementos personalizados.
- Interações implementadas com JavaScript.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização da interface, organização visual e animações.
- **JavaScript (JS):** implementação das interações e comportamentos da interface.

## 🚀 Como executar

Não é necessário instalar dependências ou configurar um ambiente complexo.

1. Clone o repositório:

   ```bash
   git clone https://github.com/RyanRHCP/animated-404-page.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd pagina-404
   ```

3. Abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão Live Server no Visual Studio Code para visualizar o projeto durante o desenvolvimento.
